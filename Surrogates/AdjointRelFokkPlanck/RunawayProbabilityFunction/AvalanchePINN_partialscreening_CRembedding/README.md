This directory contains a physics-informed neural network (PINN) that predicts the exponential "avalanche" growth rate of a relativistic "runaway" electron population as a function of typical plasma parameters that are relevant in a tokamak disruption, such as the plasma composition, initial current density, and the magnetic field. Data from a steady-state collisional-radiative model is used to infer the equilibrium temperature for a given plasma composition, which together with the initial plasma current density, provides the anticipated electric field that drives runaway electron avalanching.
