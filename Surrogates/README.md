# RunAwayPINN Surrogates
This directory contains various RunAwayPINN surrogates that use the RunawayProbabilityFunction (RPF) to describe runaway electron formation. Currently the available surrogates are (as of __,__,2025):

- Hot-tail RunAway generation
- RunAway avalanche
- RunAway decay

Some of the surrogates will contain multiple variants, which correspond to different physics fidelity.
